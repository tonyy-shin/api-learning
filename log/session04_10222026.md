# Session 04 - 10-22-2026

## Warm-up
- DELETE is idempotent; the 2nd identical DELETE usually returns 404 (state is the same, response differs)
- PATCH `{"likes": "+1"}` is NOT idempotent: each call changes state (3 → 4 → 5)
- JSON body Content-Type: `application/json` (type/subtype)

## Response Status Codes

1. **100–199: Informational**
   - **100 Continue**: client should continue the request, or ignore it if the request is already finished
2. **200–299: Success**
   - **200 OK**: request succeeded
   - **201 Created**: a new resource was created (usually POST; PUT when it creates)
   - **202 Accepted**: request accepted but not yet acted upon
   - **204 No Content**: success, no body (e.g., after DELETE)
3. **300–399: Redirection**
   - **301 Moved Permanently**: resource URL has permanently changed (see `Location` header)
   - **304 Not Modified**: cached copy is still current, no body (got one using `If-None-Match` + ETag)
   - **308 Permanent Redirect**: resource is at another URL; client must not change the HTTP method
4. **400–499: Client Error**
   - **400 Bad Request**: server can't or won't process it (malformed syntax, invalid framing)
   - **401 Unauthorized**: "I don't know who you are" (unauthenticated)
   - **403 Forbidden**: identity is known, but no access rights
   - **404 Not Found**: resource not found; sometimes used instead of 403 to hide that a resource exists
   - **409 Conflict**: request conflicts with current state (e.g., duplicate review)
   - **422 Unprocessable Content**: well-formed but invalid values (e.g., rating 7 on a 1–5 scale); FastAPI uses it for all validation errors
   - **429 Too Many Requests**: client sent too many requests (often with `Retry-After`)
5. **500–599: Server Error**
   - **500 Internal Server Error**: server hit a situation it doesn't know how to handle
   - **501 Not Implemented**: request method not supported by the server
   - **503 Service Unavailable**: temporarily down (maintenance or overloaded)

## Notes
- `requests`: `r.ok` is `status_code < 400`, so 3xx counts as "ok"
- 204 and 304 never have a body
