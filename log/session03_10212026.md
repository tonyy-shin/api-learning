# Session 03 - 2026-10-21

## Request Methods
        - Safe: Does not change the server side
        - Idempotent: State of the server stays the same no matter the number of the same requests are requested

        1. POST
                - creates new resource
        2. PUT
                - Replaces the whole resource
        3. PATCH
                - Replaces only the fields sent
        4. GET
                - gets resource
        5. DELETE
                - deletes resource
        6. HEAD
                - get with no body
        7. QUERY
                - queers server side resource without actually changing the server and returns queered resource
        8. OPTIONS
                - provides requests options available


## Things Learned
        - Difference between POST, PUT, PATCH
                1. POST - creates new resources every time with unique id
                2. PUT - Replaces the whole resource with specified content
                3. PATCH - Updates only fields sent; everything else is same
        - Idempotent
                - It is about state not response
