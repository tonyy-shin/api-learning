## Warm-up results
- PUT vs PATCH: PUT replace the whole resource with body, while PATCH only changes specified fields.
- JSON types: 6 types: string, number, boolean, null, object, array.
- Content-Type header: content-type: application/json. Tells the server how to parse it.

## What I learned
- POST gives 201 code when successful.
- JSON placeholder returns {} for 404 and delete instead of an empty body. A 204 would return nothing.
- curl -i URL > file.txt saves result of curl -i to file.txt.
