## Corrections
- Error codes should be snake_case with no spaces (`invalid_rating`, `validation_error`), since programs match on them; the message is for humans
- NASA's 500 body is an error message, not APOD data, so there's no "title" key → `KeyError: 'title'`
- Fix: check the status before reading the body
  - `if r.status_code == 200:` then read `r.json()["title"]`, else print the status
  - or `r.raise_for_status()` inside try/except
- 5xx = server's fault, often temporary → retry a few times with a wait
- 4xx = my request's fault → retrying the same request gets the same answer, so don't
- Without `load_dotenv()`, `os.getenv("NASA_API_KEY")` returns `None`; requests drops params that are `None`, so no key is sent → NASA returns 403 `API_KEY_MISSING`
