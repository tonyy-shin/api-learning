## What I learned
- URLs name resources (nouns), and HTTP methods supply the verbs
- Collection names are plural: /coaches, /reviews
- A specific resource's ID goes in the path: /coaches/42
- Query strings are better for filtering or sorting a collection: /coaches?sport=soccer
- New or updated data goes in the JSON body, not the URL
- The server assigns new IDs and returns them in the 201 response
- Stateless means each request carries everything needed to handle it
- offset = how many items to skip, limit = how many to return
- offset = (page - 1) x limit
