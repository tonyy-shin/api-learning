## Key takeaways
- curl → requests mapping (params=, headers=, json=, timeout=)
        - params= -> ?userId=1
- r.json() parses into a Python dict/list, while r.text is a str
- 201 responses return the created resource (with its new id)
- requests doesn't raise on 4xx/5xx unless you call raise_for_status()
- json array parsed into python is list, while object is parsed as dict
        - len(r.json()) gave number of dictionaries in list
- header for content-type
        - application/json;charset=utf-8
        - servers often add charset params
- POST response body
        - gives back resource you added as python dict
        - Adds server created unique id aswell
