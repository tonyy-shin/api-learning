## Client vs. Server
        1. Clients
                - A "client" is a role, not a machine
                - A client sends requests to the server
        2. Server
                - A "server" is also a role, not a machine
                - A server recieves the client's requests and responds to the client

## Client/Server Usage
        - Used for API's so that both sides of the connection can communicate with each other
        - The API uses the protocol request format by the client and gets served a protocol formatted file (JSON)
        - The client always requests and the server always serves the requests (recent updates says otherwise)
