# Log - 10/20/2026

## Request anatomy
- **Request line**: method, path + query string (optional), HTTP version
- **Headers**: key: value metadata. Common ones: Host (required), User-Agent, Accept, Content-Type, Authorization
- **Body** (optional): usually JSON, plain text, or form data; Content-Type says which

## URL anatomy
- **Scheme**: https / http
- **Host**: www.google.com
- **Path**: /search
- **Query** (optional): ?q=rit+soccer, key=value pairs joined by &

## DevTools
- Network tab only records while open, so reload after opening
- Firefox "Request" tab = Chrome "Payload" tab

## Learned
- POSTs can have no body (Google's gen_204 puts everything in the query)
