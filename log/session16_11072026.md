## What I learned
- Path = which resource. Query string = how I want the list (filter, sort, page)
- Several filters combine as AND. No matches -> 200 with an empty list, not 404
- sort=field is ascending, sort=-field is descending. Unknown sort field -> 422
- Always have a default sort so pages don't repeat or skip items
- Set a default limit and a max limit. The next link keeps the filters and sort
- Breaking change (rename, remove, change a type) -> /v2. Adding a field or param stays /v1
