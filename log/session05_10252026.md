## JSON Data Types

| Type    | Example                      | Python equivalent |
|---------|------------------------------|-------------------|
| string  | `"Tony"`                     | `str`             |
| number  | `2`                          | `int` / `float`   |
| boolean | `true`                       | `True` / `False`  |
| null    | `null`                       | `None`            |
| object  | `{"Left Back": "Tony Shin"}` | `dict`            |
| array   | `[1, 2, 3]`                  | `list`            |

## loads and dumps

- `json.loads(text)`: JSON string → Python objects
  - converts types to Python equivalents (`true` → `True`, `null` → `None`)
- `json.dumps(obj)`: Python objects → JSON string
  - converts types back to JSON (`True` → `true`, `None` → `null`)
- `json.load` / `json.dump` (no "s") do the same thing with files instead of strings

## Things I learned

- JSON object keys have to be strings
- Strings and keys need double quotes
- Booleans are `true` in JSON and `True` in Python
