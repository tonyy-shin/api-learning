## Key ideas
- Type hints and Query rules are a gate in front of the function: bad values
  get 422 before my code runs; missing optional values use the default
- 422 = readable request that breaks a rule (same as Week 3)
- Rejecting limit=0 is better than [] so the client learns its request was wrong
