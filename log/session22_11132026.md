## What I learned
- A POST that creates something returns 201, not 200
- Missing field = readable JSON that breaks a rule → 422 (not 400)
- Pydantic converts values when the meaning is clear ("4" → 4); "four" → 422
- Validation runs BEFORE my function: b and c never ran my code
- raise HTTPException stops the function before the counter line, so e got id 2
- 422 body: `loc` = where (body/path + field), `type` = which rule failed
- FastAPI's {"detail": [...]} isn't my Week 3 error shape yet (Friday)
